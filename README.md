# Site instituto31.pt

Páginas estáticas do site público do Instituto 31.

- Raiz: as páginas publicadas (index.html, cursos, psicotécnicos…).
- `assets/`: imagens, `marcar.js` (marcação de psicotécnicos com MB WAY) e `site.css`.
- `_fonte/`: script de geração, funções do Supabase e migração da base de dados.

Os dados (marcações, pedidos) ficam no Supabase. Este repositório não tem chaves nem dados pessoais.
